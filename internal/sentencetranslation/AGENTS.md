# Sentence translation module

- This package owns the durable sentence translation record: one saved
  translation per source sentence in the article's target language
  (`sentence_translation`, keyed to the exact source anchor).
- Dependency direction: the record layer uses library and store only. The
  service and worker additionally use analysis (history), jobs, pipeline,
  prompts, and annotator (contract/executor), mirroring `internal/dictionary`.
  HTTP handlers (checkpoint 10) import this package; no reader/semantics/
  annotator package may import this one.
- Every write verifies the live anchor first: the sentence must still exist
  with the captured source hash, and the target language must match the
  owning article. Deleted or recreated anchors fail with `ErrStaleAnchor`
  and never remap a result to another sentence.
- The output contract is `sentence.translation.v1` (owned by
  internal/annotator): closed object with exact const identity fields
  (`version`, `sentence_id`, `source_hash`) and nonblank plain-text
  `translation_en` up to 8,000 Unicode scalars. No HTML, no extra fields.
- Saved translations persist across reload and restart and are never
  regenerated by rereads or settings changes. There is no cross-article
  sentence cache.
